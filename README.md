# Stock Portfolio Tracker (Python)📈 

#  Project Overview📌

The Stock Portfolio Tracker is a simple Python-based application that calculates the total investment value of stocks based on predefined stock prices and user-entered quantities.

This project was developed as part of my CodeAlpha Python Developer Internship to practice Python programming fundamentals and file handling.

# ✨Features:

- 📊 Predefined stock prices using a Python dictionary.
- ⌨️ User input for stock symbols and quantities.
- 🧮 Automatic calculation of individual stock investment values.
- 💰 Calculation of total portfolio investment.
- ✅ Validation of stock symbols.
- 📄 Displays a portfolio summary in the terminal.
- 💾 Saves portfolio details to a "portfolio.txt" file.

# 🛠️Technologies Used:

- Python 3
- Dictionaries
- Variables and data types
- Loops and conditional statements
- User input and output
- File handling

# 🚀 How to Run the Project:

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

Replace "YOUR_GITHUB_REPOSITORY_URL" with your actual GitHub repository URL.

2. Open the Project Folder

cd CodeAlpha_Stock-Portfolio-Tracker

3. Run the Python Program

python stock_portfolio_tracker.py

4. Enter Stock Details

Enter a stock symbol and its quantity when prompted.

Supported symbols include "AAPL", "TSLA", "GOOGL", "MSFT", and "AMZN".

Type "done" when you have finished entering stocks.

The program displays the portfolio summary and saves the report to "portfolio.txt".
